
# MediCare+ | Digital Healthcare Website

MediCare+ is a modern and responsive healthcare website developed as an IT Workshop project.  
It is designed to provide users with easy access to healthcare services like online appointments, video consultations, health monitoring, emergency help, medical records, and patient feedback.

This project focuses on creating a professional healthcare platform using frontend web technologies with an attractive UI/UX design.

---

##  Features

- Modern Responsive Healthcare Website
- Attractive Hero Section with 3D Card Design
- About Us Section
- Services Section
- Login Form with Validation
- Registration Form with Validation
- Feedback / Contact Form
- Emergency Contact Information
- Animated Counters
- Scroll Reveal Effects
- Floating Particle Background
- Professional Footer Section
- Mobile Friendly Design

---

## Project Purpose

The main purpose of this project is to create a user-friendly digital healthcare platform where patients can easily connect with healthcare services anytime and anywhere.

It also demonstrates frontend development skills, UI/UX design understanding, and practical implementation of HTML, CSS, Bootstrap, and JavaScript.
